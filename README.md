# Kelola Barang

Aplikasi manajemen barang berbasis web yang dibuat sebagai project kelas 12 semester 1.

## 🛠️ Teknologi
- HTML
- CSS
- PHP

## ✨ Fitur
- Login & autentikasi pengguna
- Tambah, edit, dan hapus data barang
- Manajemen stok barang
- Laporan stok barang

## 📁 Cara Menjalankan
1. Clone repo ini
```bash
   git clone https://github.com/esselrn/kelola-barang.git
```
2. Pindahkan folder ke direktori server lokal (contoh: `htdocs` untuk XAMPP atau `www` untuk Laragon)
3. Import database dari folder `/database` (jika tersedia)
4. Jalankan **XAMPP** atau **Laragon**, aktifkan Apache & MySQL
5. Buka browser dan akses `http://localhost/kelola-barang`

## 📝 Catatan
Project ini dibuat untuk keperluan tugas sekolah dan tidak di-deploy secara publik.
